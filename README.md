# Health Body — массажный кабинет в Астане & RAG База знаний

Сайт массажного кабинета с интегрированной легковесной RAG-системой (Retrieval-Augmented Generation) и панелью управления документами.

## Возможности
- **Сайт и витрина услуг:** адаптивный лендинг массажного кабинета с каталогом услуг, ценами и формой записи.
- **Интерактивный консультант (чат-бот):** онлайн-виджет на сайте. Отвечает на вопросы посетителей строго по загруженной базе документов, указывает источники и отсекает нерелевантные вопросы без вызова платной модели.
- **Админ-панель базы знаний (`/admin`):**
  - Авторизация по паролю из переменной окружения `ADMIN_PASSWORD`.
  - Загрузка файлов `.txt` и `.md` (лимит 1 МБ с защитой от 413).
  - Безопасная очистка названий с полной поддержкой кириллицы (включая букву «ё»).
  - Просмотр списка документов, количество фрагментов, размер и дата.
  - Удаление документов (с автоматическим каскадным удалением фрагментов).
  - Переиндексация на основе сохранённого исходного текста.
- **Локальное хранилище без тяжёлых зависимостей:** SQLite через нативный встроенный модуль Node.js (`node:sqlite`). Векторы и косинусное сходство вычисляются на нативных массивах.
- **Безопасность:**
  - API-ключи никогда не попадают на клиент и в логи.
  - Ограничение частоты запросов (rate limiting) по IP.
  - Защита от prompt injection (фрагменты подаются модели как изолированные данные).

## Требования к рантайму
- **Node.js:** версии **`>= 22.5.0`** (протестировано на Node.js v25.6.0). Начиная с версии 22.5.0 доступен встроенный нативный модуль `node:sqlite`.
- Сторонние npm-зависимости не требуются (zero dependencies).

## Быстрый старт

### 1. Настройка переменных окружения
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```
Заполните параметры в `.env`:
```ini
OPENAI_API_KEY=sk-...         # Ваш API-ключ OpenAI
ADMIN_PASSWORD=admin2026       # Пароль для доступа в /admin
PORT=3000                     # Порт сервера (по умолчанию 3000)
RAG_THRESHOLD=0.30            # Порог сходства (по умолчанию 0.30)
OPENAI_CHAT_MODEL=gpt-4o-mini # Модель генерации ответов
```

### 2. Запуск сервера
```bash
npm start
# или напрямую:
node --env-file-if-exists=.env server.js
```
Сайт будет доступен по адресу: [http://localhost:3000/](http://localhost:3000/)  
Админ-панель базы знаний: [http://localhost:3000/admin](http://localhost:3000/admin)

## Как загрузить документ в базу знаний
1. Откройте сайт [http://localhost:3000/](http://localhost:3000/) и перейдите по ссылке **«База знаний (Админка)»** в футере (или сразу откройте `/admin`).
2. Введите пароль администратора (по умолчанию `admin2026` или значение `ADMIN_PASSWORD`).
3. В блоке «Загрузить документ» перетащите или выберите файл формата `.txt` или `.md` (до 1 МБ).
4. Документ автоматически нарежется на смысловые фрагменты (500–800 символов с перекрытием ~100 символов), получат векторные представления и появятся в таблице документов.
5. Задайте вопрос в виджете чата на главной странице сайта — бот ответит с указанием источника.

## Тестирование и калибровка (Eval)
Для автоматической проверки RAG-пайплайна, точности ответов и калибровки порога ловушек запустите:
```bash
npm run eval
```
Скрипт читает вопросы из `eval/questions.json` (3 тематических вопроса и 1 ловушка с `"trap": true`), рассчитывает косинусные сходства и валидирует, что ловушка гарантированно отсекается порогом, а обычные вопросы успешно вызывают модель.
